# Fake Flag

满屏随机国旗网格前的 3D 视频旗帜。包含金属旗杆、圆球杆头，以及从 Blender 导出的阵风、卷折、下垂动画。没有地面或页面文字。背景为 265 张 SVG 旗帜组成的无缝 3:2 网格，每两秒重新随机抽取、排列。

在 VS Code 中打开本文件夹，右键 `index.html` → **Open with Live Server**。不要用 `file://` 直接打开，浏览器会拦截模型加载。

所有依赖均在本地，无需 npm、构建工具或外部 CDN。可直接作为 GitHub Pages 的 `/fake_flag/` 静态目录部署。

- `index.html`：网页入口
- `main.js`：模型导入、视频材质、白底灯光与响应式取景
- `assets/flag.glb`：Blender 导出的真实 3D 模型和 10 秒循环动画
- `assets/fake_flags.mp4`：视频旗面
- `vendor/`：Three.js 0.170.0 和 MIT 许可证

动作完整周期包含首尾重合的 0/10 秒姿态；播放在 10 秒前回绕，不重复终点。网页使用视频媒体时钟驱动模型，避免视频和动作逐渐错位。浏览器禁止自动播放时会出现“点击播放”，正常播放后页面只保留旗帜。

## 随机国旗背景

`background.js` 负责网格大小、素材预加载和每两秒刷新。`assets/flags/` 保留桌面 `3_2` 文件夹的全部 265 张 SVG。每格按前景旗面展开宽度估算，保持 3:2，无间隙；视口边缘仅裁切溢出部分。相邻两次刷新会避免同一格保留相同旗帜。

加载随机素材前，以优先加载的 `CN.svg` 中国国旗平铺填满背景；SVG 清单第一项也是 `CN.svg`。

随机策略：265 张素材全部洗牌后逐张取用，用完一轮再洗牌。每两秒换组，一轮内不重复；跨轮时尽量避免同屏重复。首屏中国国旗以 SVG 直接内嵌于 CSS，五颗星位于左上区域，不依赖图片请求完成。网站内的 CN.svg 已修正布局，桌面原素材未修改。

部署检查：素材清单与 Git 中的文件名逐一匹配（包括大小写），避免 Mac 本地可用、GitHub Pages 上 404。网页中国国旗文件为 `assets/flags/cn.svg`。若素材有加载失败，控制台会报告文件名，随机刷新不会默默退化为只从部分旗帜抽取。
